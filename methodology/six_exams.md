# 六考场定义 · 判什么、怎么判、什么算死

> 前置第 0 考场 + 六个考场。全部判据在 PREREG 里**跑前冻结**,跑完不改参数。
> 判死 = 当场归档,不调参救(参数救不了毛信号为负的想法,见公开案例 1 的消融章节)。

## 第 0 考场 · 执行语义(前置,A 股永远第一个跑)

**判什么**:成交价假设能否在现实里成交。
**死刑线**:不可成交 → 全部统计作废,后面不用看。

- A 股:信号日收盘价成交 = 把封死涨停(约 1.2% 的收盘日)、次日继续冲高的票
  "自动买进"了——实盘你根本买不进。正确口径 = 次日开盘成交 + 涨停禁入。
- 期货:次根开盘成交,可过夜;滑点按跳数计,跳空穿越按劣价(开盘价更差则按开盘价)。
- 公开案例 2 就死在这一格:随机对照三次过门的模型,改了成交语义当场归零。

## 考场 1 · 毛信号(死刑线)

**判什么**:把手续费和滑点**全部设成零**后的总毛利。
**死刑线**:毛利 ≤ 0 → 判死,不再往下。

成本设零还在亏,说明亏在信号本身,不是亏在成本。反过来说,毛利为正也只说明
"有资格进考场 2"——死刑线是入场券,不是毕业证。

## 考场 2 · 净利 t

**判什么**:扣完成本后,逐笔净盈亏的 t 值。
**死刑线**:|t| < 2 → 无 edge。

t 值是对"这批交易的平均每笔盈利是不是零"的检验。毛利为正、净利 t 不显著,
是成本侵蚀型死法(毛利全被手续费和滑点吃掉)。

## 考场 3 · IS-OOS

**判什么**:把样本切成样本内(IS)/样本外(OOS),参数只在 IS 里选,OOS 只验一次。
**死刑线**:OOS 翻负或与 IS 方向相反 → 过拟合。

## 考场 4 · Top5 集中度

**判什么**:把盈利最大的 5 笔剔除,剩下的还赚不赚。
**死刑线**:剔除 Top5 后转负 → 右尾独供,利润是几笔 outlier 撑起来的,不可复制。

## 考场 5 · 随机超额(护城河)

**判什么**:同数量、同成本、同出场机制的**随机入场**跑 N 次,得到每笔净盈亏的
分布;策略的每笔净盈亏落在分布第几百分位。
**死刑线**:不超过随机 P50 → 信号无增量;超过 P50 但不及 P95 → 需结合 t 值判读。

实现见 [`code/random_baseline.py`](../code/random_baseline.py)。注意口径:
随机基线回答的是"信号比乱买好多少",不是"策略能不能赚钱"——它杀伪,不证真。

## 考场 6 · 账户层(仅披露,不作判据)

**披露什么**:最大回撤、手数与资金阶梯、熔断阈值下的账户存活。
**为什么只披露**:账户层(仓位、杠杆、熔断)改变的是死法,不改变信号有没有 edge。
信号层判死的东西,账户层救不回来;信号层没判死的东西,才轮到账户层说话。

## 反钓条款

- 预注册消融清单外的变体,跑前要补写进 PREREG,不许"跑完看到什么顺手再试一个"。
- 翻案条件:**全部**变体同向过门。单个变体转正(比如方向镜像在日线转正、
  30 分钟转负)不构成翻案。
- 多重检验:每加一次考场,冒出的"幸存者"都要打折。这就是为什么判据在跑前冻结。
