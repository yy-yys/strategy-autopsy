# strategy-autopsy · 量化策略验尸框架

我不保证你的想法赚钱。我保证给你一份按预注册流程跑完的验尸报告,
告诉你它值不值得上实盘。大部分想法会死,死了比你上实盘亏得少。

> **本框架每个结论都附带随机对照基线**——同一套成本、同一批品种,随机入场的表现是多少。
> 没有这条,胜率数字毫无意义。

---

## 为什么需要随机对照

**一、胜率的分母问题。** 高胜率经常是真的,但只统计了"活到终点的那一半腿"。
一个宣称 88% 胜率的均值回归策略,把被止损砍掉的腿放回分母后,整场胜率是 36.9%
(见[公开案例 1](examples/01_futures_cci_mean_reversion/report.md),运行日志全量公开)。两个数字都有出处,
区别只在文章有没有把止损腿放回来。

**二、幸存者不在样本里。** 你看到的回测大多用"今天还活着的股票、没有退市的数据、
能成交的价格"。一个 A 股全市场选股模型,随机对照门控三次通过、样本期 +16,160%,
验尸发现全部收益住在买不到的收盘价上——现实成交口径 7 年全负
(见[公开案例 2](examples/02_astock_limit_up_fill/report.md))。

**三、随机基线怎么算。** 把策略的入场信号扔掉,换成**同数量、同成本、同出场机制**
的随机入场,跑几百次,看策略能不能跑赢这个分布。跑不赢,说明"信号"没有增量,
利润(如果有的话)属于运气或beta。这是本框架的护城河,也是它和"挂 99 验尸"的
同行之间唯一的硬差异。

## 前置检查 + 六考场

| # | 考场 | 判什么 | 死刑线 |
|---|---|---|---|
| 0 | 执行语义 | 成交价假设能否现实成交(A 股收盘价成交 = 把涨停白送给策略) | 不可成交 → 全部统计作废 |
| 1 | 毛信号 | 成本设零后的毛利 | ≤0 → 判死,不再往下 |
| 2 | 净利 t | 扣完成本后每笔净盈亏的 t 值 | \|t\| < 2 → 无 edge |
| 3 | IS-OOS | 样本内/样本外切分 | OOS 翻负 → 过拟合 |
| 4 | Top5 集中度 | 利润是否被极少数笔撑起 | 剔除 Top5 转负 → 右尾独供 |
| 5 | 随机超额 | 对比同窗随机入场分布 | 不超过随机 P50 → 无增量 |
| 6 | 账户层 | MDD / 熔断 / 手数 | 仅披露,不作判据 |

规则跑前全部冻结([PREREG 模板](methodology/PREREG_TEMPLATE.md)),跑完不改参数,
不补跑"再试一个变体"。翻案必须全部变体同向过门。

## 公开案例

- **[期货卷 · CCI 均值回归](examples/01_futures_cci_mean_reversion/report.md)** —
  宣传胜率 88%,实测整场 36.9%。45 个商品期货品种 × 六周期,18 格 0 存活;
  死因:2% 止损把 56.7% 的腿在回归走完之前砍掉,砍掉的损失吃光全部回合利润。
  运行现场全量公开([logs/](examples/01_futures_cci_mean_reversion/logs/):六周期逐笔 +
  控制台输出);v1 曾因现场缺失作废,按冻结规格复跑后判决结构逐格复现。
- **[A股卷 · 涨停填充幻影](examples/02_astock_limit_up_fill/report.md)** —
  随机对照三次过门、累计 +16,160% 的选股模型;94,039 个收盘涨停非一字样本的探针证明
  幻想成交 +1.60%/日、现实成交 −0.25%/日,幻影差 453 个百分点/年,判决作废。
- **[自研卷 · 日线趋势](examples/03_self_daily_trend/report.md)** —
  五张稳健性表全过(净 PF 1.32、集中度 21.6%、符号一致性 65.2%、成本三倍仍 1.30),
  按年拆开五年三亏;剔除最好一年 283 笔 PF 0.96;盈利最多十笔占净利 116.8%。
  判决:**不部署**。框架同样用来否掉自己的存货,参数数值隐去。
