# PREREG — 分批止盈+移动止损(视频策略)× 6周期矩阵

冻结时间: 2026-10-02 23:00(跑批前)。本金口径 **10万**(用户指定)。
策略文案: 用户提供的简易量化视频"主动止盈如何让资金曲线更平滑"——
趋势/波段策略 + 分批止盈(盈利达X或ATR阈值后平1/N, 可循环) + 移动止损(剩余仓位跟踪) + 趋势反转平剩余仓位。
**宣称量化指标(视频原文)**: 收益略低 / 回撤更低 / 盈亏比下降 / 胜率上升 / 夏普可能更高 / 卡玛大概率更高。

## 0. 黑名单前置项(爆仓型1-4例范式升级, 强制)

- **固定手数前置**: 主判据=固定2手/笔资金无关(1手无法分批, 2手=最小可分批单位; A0/B1/B2/C1四臂同注码, A/B才公平)。风险平价手数只作10万账户披露, 不作主判据。
- 本策略出场族=吊灯ATR跟踪(非"极值锚×千分比×时间衰减"黑名单模板), 但移动止损腿单独消融(B2), 与JSBD跟踪止损腿尸检口径一致。
- 吊灯类出场禁用 BacktestEngine(其止损撮合写死 min(bar_low,stop) 对吊灯出场是支配性偏差, MAMomentum +37%虚高/OrbChand两批已证) → **复用势核自建事件循环**(_shie_core 管道), 止损成交=min(开盘,止损线), 滑点进费用不进成交价。
