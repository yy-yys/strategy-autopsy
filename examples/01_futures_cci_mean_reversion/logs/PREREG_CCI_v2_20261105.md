## 3. 信号与出场

- CCI(N) = (TP − SMA(TP,N)) / (0.015 × MD);TP=(H+L+C)/3;MD=窗口内 |TP−SMA(TP)| 均值
  (sliding_window_view 向量化,自检对拍循环参考);MD=0(平盘)时 CCI=0。
- 事件:CCI 上穿 −100 → 多头;CCI 下穿 +100 → 空头。事件在**收盘确认**,次根开盘执行。
- 反手制:持仓中对向事件 → 次根开盘平旧仓并同价开反仓(一笔腿记"反手"出场,
  新腿同根同价入场)。持仓中同向事件一律忽略(不加仓)。
- 2% 固定止损:多头 entry×0.98 / 空头 entry×1.02,入场次根起逐根检查,
  盘中触及按止损价成交,跳空穿越按开盘劣价,记"止损"出场。
- 样本末持仓按最后收盘强平,记"期末"。
- 出场原因编码只有三种:反手 / 止损 / 期末(消融"多头 only"下出现第四种:信号)。

## 5. 口径定义(报告按此出数,客户问题按此答)

- 每笔毛盈亏 pnl_g = (出场价−入场价)×方向×乘数×1手(复权脊线,0 成本口径)。
- 每笔净盈亏 pnl1_base = pnl_g − base 成本。
- **合计(毛值)= Σpnl_g;合计(净值)= Σpnl1_base;均值 = 合计(净值)/笔数。**
- 胜率、PF 均为**净值口径**(盈利笔数占比;净盈利和/|净亏损和|,pool_stats 注册实现)。
- 0 成本口径的胜率/PF 另列披露。
- 表 2 分解 = 按出场原因分堆(反手/止损/期末),各堆给:笔数、毛值合计、净值合计、
  净值均值、净值胜率。**毛值合计之和 = 全案卷 0 成本毛利(差 = 各堆覆盖外的笔数,
  运行日志逐笔可查)。**
