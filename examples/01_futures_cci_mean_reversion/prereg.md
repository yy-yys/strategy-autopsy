## 1. 命题

委托方提供一篇流传较广的均线偏离度想法:CCI(10) 振荡器上穿 −100 买入、
下穿 +100 卖出、反手制,配 2% 固定止损。原文宣称 Lambert 本人回测胜率 88%,
"±100 阈值 + 10 日周期是经过验证的最优参数"。

## 2. 规格冻结

- 池:45 个商品期货主力连续合约(逐品种数据起点见运行日志开头清单)
- 周期与数据源(写死,含起点):
  - 日线 = 日线库全窗,2016-01 → 2026-11(主流品种 2,628 根)
  - 30m = 30 分钟库全窗(~2021-08 起),60m = 30m 重采样
  - 15m = 15 分钟库全窗(39 品种,2024-01 起)
  - 5m = 5 分钟主连库(精确切换点加性复权,2024-01 起),10m = 5m 重采样
- 成本:0(毛信号口径)/ base(手续费 + 2 跳/边)/ press(4 跳/边)
- 成交假设:信号根收盘确认 → 次根开盘成交;跳空穿越止损按开盘劣价;
  入场根不检止损;样本末强平
- 记账:信号与点数盈亏走复权脊线,费用走原始价

## 3. 信号与出场

- CCI(N) = (TP − SMA(TP,N)) / (0.015 × MD);TP=(H+L+C)/3;MD=窗口内 |TP−SMA| 均值;
  MD=0(平盘)时 CCI=0。向量化实现,自检对拍循环参考。
- 事件:CCI 上穿 −100 → 多头;CCI 下穿 +100 → 空头;收盘确认,次根开盘执行。
- 反手制:持仓中对向事件 → 次根开盘平旧仓并同价开反仓(记"反手"出场);
  同向事件一律忽略。
- 2% 固定止损:多头 entry×0.98 / 空头 entry×1.02,入场次根起逐根检查,
  跳空穿越按开盘劣价(记"止损"出场)。
- 样本末持仓按最后收盘强平(记"期末")。出场原因编码只有:
  反手 / 止损 / 期末(消融"多头 only"下出现:信号)。

## 4. 考场

毛信号(死刑线)/ 净利 t / IS-OOS(切点冻结:daily 2024-01-01,30m·60m 2025-01-01,
15m 2025-10-01,10m·5m 2025-07-01)/ Top5 集中度 / 随机超额(3 种子)/ 账户层(仅披露)

## 5. 口径定义(报告按此出数)

- 每笔毛盈亏 = (出场价−入场价)×方向×乘数×1手(0 成本口径);
- 每笔净盈亏 = 毛盈亏 − base 成本;
- 合计(毛值)= Σ毛盈亏;合计(净值)= Σ净盈亏;均值 = 合计(净值)/笔数;
- 胜率、PF 均为净值口径(0 成本口径另列披露);
- 表 2 分解按出场原因分堆,各堆给:笔数/毛值合计/净值合计/净值均值/净值胜率;
  各堆毛值相加 = 全案卷 0 成本毛利,逐笔可查。

## 6. 预注册消融(跑前冻结,超出另议;日线 + 30m 两考场)

1. 止损:无 / 1% / 3%(主读 2%)
2. 周期邻域:N ∈ {14, 20}
3. 带宽:±200
4. 多头 only(空头禁入,对向事件只平不反)
5. 方向镜像(下穿 +100 买入 / 上穿 −100 卖出)

## 7. 随机对照

同一台事件循环机器(反手/止损/期末全保留),事件源替换为随机(同事件数、
随机时点、随机方向),3 种子。随机超额 = 策略每笔净值均值 − 随机每笔净值均值。

## 8. 不做

换物种、加趋势闸、截面化——均须另立预注册。

## 9. 判决规则

- 死刑线:0 成本毛利 ≤ 0 → 判死归档
- 翻案:全部消融变体同向过门,缺一不翻
