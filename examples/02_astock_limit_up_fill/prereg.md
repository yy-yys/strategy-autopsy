# PREREG · 案卷 STK-20261031(公开样例)

日期:2026-10-31    SKU:01 验尸(A股卷)

## 1. 命题
委托方带来一个 A 股全市场选股模型:机器学习排名打分取 Top5、每日调仓。
回测**三次通过事先冻结的随机对照门控**(净夏普超过同窗随机组合 200 次种子的
95 分位),样本期累计净收益 +16,160%。委托方的问题只有一个:"能不能上实盘。"

## 2. 规格冻结
- 面板:5,331 只 A 股(**含退市**),2020-01 → 2026-10
- 数据:外部 PIT 源,双源对拍
- 门控:随机对照 200 种子,95 分位(跑前冻结)
- 执行语义(第 0 考场):
  - A 口径(委托方原样):信号日收盘价成交,close-to-close
  - B 口径(诚实语义):次日开盘价成交,open-to-close,**涨停禁入**
  - 涨停探针:全部入选样本的信号日涨停率 vs 全市场基率
- 主判据:B 口径下净利 t ≥ 2

## 3. 考场
执行语义(第 0 考场,A 股永远第一个跑)/ 随机对照 / IS-OOS / Top5 集中度 / 账户层

## 4. 预注册消融(跑前冻结)
1. 成交价语义 A ↔ B 对调
2. 涨停禁入开/关
3. hold 期展开/滚动两种口径

## 5. 不做
换因子、调排名权重、换池——均须另立预注册。

## 6. 判决规则
- 第 0 考场不可成交 → 全部统计作废,不再读后续考场
- 翻案:全部变体同向过门
